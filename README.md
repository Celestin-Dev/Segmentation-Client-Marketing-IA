# Projet Segmentation Client & Marketing IA

## 📖 Description

Ce projet exploite des données clients, produits, ventes et marketing pour :
- Segmenter les clients par comportement d'achat (clustering)
- Analyser les performances des campagnes marketing (ROI, CPC, CPA, taux de conversion)
- Prédire le churn ou la valeur client (CLV) à l'aide de modèles de machine learning
- Proposer une stratégie marketing digitale personnalisée par segment
- Visualiser l'ensemble via un dashboard interactif (Streamlit)


## 🛠️ Prérequis

- [Git](https://git-scm.com/downloads) installé
- [Python 3.10+](https://www.python.org/downloads/) installé

## 🚀 Installation en local

**1. Cloner le repo**

```bash
git clone https://github.com/Celestin-Dev/Segmentation-Client-Marketing-IA.git
cd Segmentation-Client-Marketing-IA
```

**2. Créer un environnement virtuel**

```bash
python -m venv venv
```

Activer l'environnement :

```bash
# Sur Windows
venv\Scripts\activate

# Sur macOS / Linux
source venv/bin/activate
```

**3. Installer les dépendances**

```bash
pip install -r requirements.txt
```

**4. Lancer le dashboard en local**

```bash
streamlit run dashboard/app.py
```

Le dashboard s'ouvre automatiquement dans le navigateur à l'adresse `http://localhost:8501`.
